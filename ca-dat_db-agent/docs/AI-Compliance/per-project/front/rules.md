# Per-Project Rules: front/

> `~/git/front/` — Monorepo with 30+ web projects, GitHub Pages portfolio

## Project-Specific BLOCKs

| Pattern | Message |
|---------|---------|
| `style=""` in .html/.svelte/.vue | No inline CSS — create class in `_*.scss` |
| `export let` in .svelte | Svelte 5 runes: `let { prop } = $props()` |
| `on:click\|on:input` in .svelte | Svelte 5: `onclick={handler}` |
| Edit root `front/package.json` | Auto-generated by `deploy.sh deps` — edit project `package.json` |
| Edit `dist/` files | Generated by `build.sh build` — edit source |
| `npm run build\|dev` directly | Use `./build.sh build` or `./build.sh dev` |

## Project-Specific WARNs

| Pattern | Message |
|---------|---------|
| `: any` in .ts/.tsx | Strict mode — define proper type |
| `$:` reactive in .svelte | Use `$derived()` or `$effect()` |
| `data()\|methods:\|mounted()` in .vue | Use Composition API `<script setup lang="ts">` |
| `float: left\|right` in .scss | Use flexbox/grid with Golden Mixins |
| Missing Matomo tracking in `<head>` | All projects must include analytics |
| `npm install` in project subdir | Deps via project `package.json` + `deploy.sh deps` |

## Code Standards

### TypeScript (strict)
- No `any` — handle `null`/`undefined`
- DOM: cast elements, check null
- ES Modules: `import`/`export`

### Svelte 5 (runes)
```typescript
let { propName }: { propName: Type } = $props();
let count = $state(0);
let doubled = $derived(count * 2);
// onclick, not on:click
```

### Vue 3 (Composition API)
```typescript
// <script setup lang="ts">
defineProps<{ id: number }>();
const user = ref<User | null>(null);
```

### SCSS
```scss
@include mq(sm|md|lg|xl)
@include flex-center;
@include flex-row(justify, align, gap);
@include grid-auto-fit(min-size, gap);
```

## Build System

- Every project: `build.sh` (engine) + `build.json` (config) at project root
- Master build: `~/git/front/1.ops/build_main.sh`
